# Quiz en Images - TP Android

## Description
Cette application est un jeu de quiz composé de cinq questions illustrées. L'utilisateur doit observer une image et choisir la bonne forme géométrique parmi trois boutons.

## Fonctionnalités
- Affichage de 5 questions statiques avec images.
- Gestion du score et d'une barre de progression.
- Feedback immédiat après chaque réponse (Juste/Faux).
- Écran final avec score total.
- Possibilité de rejouer.
- Support de la rotation d'écran (sauvegarde d'état).

## Comment lancer le projet
1. Ouvrez **Android Studio**.
2. Sélectionnez **File > Open** et choisissez le dossier racine du projet.
3. Attendez la fin de la synchronisation Gradle.
4. Connectez un appareil Android ou lancez un émulateur (API 24 minimum).
5. Cliquez sur le bouton **Run** (flèche verte).
