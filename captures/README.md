# Dossier des captures d'écran

Placez ici les 4 captures d'écran requises pour le TP :
1. **Une question** avec son image, ses trois boutons, le score en haut à droite et la barre de progression.
2. **Une bonne réponse** avec le score mis à jour.
3. **Une mauvaise réponse** avec le score inchangé.
4. **L'écran final** avec le score obtenu.
